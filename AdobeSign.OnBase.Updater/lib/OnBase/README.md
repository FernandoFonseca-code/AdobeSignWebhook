# Hyland assemblies (not included)

`Hyland.Unity.dll` and `Hyland.Types.dll` are licensed by Hyland and are not distributed with this repository. Copy them into this folder before building:

```
AdobeSign.OnBase.Updater\lib\OnBase\Hyland.Unity.dll
AdobeSign.OnBase.Updater\lib\OnBase\Hyland.Types.dll
```

Use the versions that match your OnBase Application Server. You can usually find them in the Unity API / SDK folder of your OnBase installation, or in the `bin` folder of an existing Unity client or Application Server. Ask your OnBase administrator or Hyland support if you can't locate them.

The project was built and tested against Unity API 25.1.
